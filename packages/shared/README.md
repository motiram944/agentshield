# @agentshield/shared

> **Shared domain models, contracts, and type definitions for AgentShield.**

[![npm version](https://img.shields.io/npm/v/@agentshield/shared.svg)](https://www.npmjs.com/package/@agentshield/shared)
[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](../../LICENSE)

---

## Overview

`@agentshield/shared` provides the central TypeScript types, enums, event definitions, and interface contracts utilized across `@agentshield/core`, `@agentshield/node`, `@agentshield/next`, and `@agentshield/browser`.

---

## Installation

```bash
npm install @agentshield/shared
```
